## Concepts Learned

- `input()` always returns a string.
- Numbers entered by the user must be converted before performing calculations.
- Strings and integers cannot be concatenated directly.
- `int()` converts text into integers.
- `float()` converts text into decimal numbers.
- Different arithmetic operators perform different mathematical operations.

---

## Challenges Faced

While printing the user's age, I received the following error:

```
TypeError: can only concatenate str (not "int") to str
```

I learned that integers must be converted to strings before concatenation, or printed using commas.

---

## Key Takeaways

- Always check the data type before performing operations.
- Use `int()` and `float()` when numerical calculations are required.
- Python provides several arithmetic operators for different mathematical operations.
